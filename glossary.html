HTML and CSS Glossary

Section 2-HTML

element
An element is a piece of content and the specific meaning it carries, as wellas the code used to mark it up
tag
The code that delineates an element is called tags
Paragraph
Default text is used when you code a paragraph tag
self-closing elements
There are some elements that dont need a closing tag because they don't wrap around any content

Section 4- Skeleton Code

doctype
lets the browser know which version of HTML the document uses
title
It is what shows in the browser tab and in search listings on Google and other search engines
body
Element that holds all content that is for display on the page itself
meta viewport
This code indicates that the browser should not zoom in on the page and should respect and responsive CSS code

Section 5- Basic HTML Basics

headings
sections titles an HTML document
small
represents text that is less important, a side comment, copyright, or legal information
strong
An inline element used to add importance to text. By default and most commonly, it makes the text bold.
Unordered lists
the ul element represents a list of items, where the order of the items is not important- that is, where changing the order would not maternally change the meaning of the list
